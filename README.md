# Azhar Cloth Shop Website

A simple, fast, mobile-friendly website. No installation needed.

## Open it
Double-click `index.html`.

## Edit your details
Open `script.js` and change the SHOP block at the top:
- `whatsapp`: your number in international format, digits only (e.g. 923001234567)
- `phoneDisplay`: how the phone number appears on the page
- `address`: your shop address

Opening hours, reviews and the about text can be edited directly in `index.html`.

## Put it online
Upload all files to any static host (Netlify Drop, GitHub Pages, Cloudflare Pages, or your hosting's public_html folder).

## Files
- index.html - page content
- style.css - design
- script.js - menu, filters, WhatsApp links
